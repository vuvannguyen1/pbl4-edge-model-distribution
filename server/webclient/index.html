Model Camera Đánh giá

Xin model phát hiện vật thể

Server chọn model vừa với mạng và cấu hình máy này, gửi từng miếng; máy kiểm tra rồi lưu lại để lần sau dùng ngay.

Dùng để
Ưu tiên tốc độ: server chọn model chạy được ít nhất 5 khung hình/giây trên máy này.
Tuỳ chọn nâng cao
Server chỉ chọn model tải xong trong thời gian này ở băng thông đo được.

    Máy này

    Model đã lưu trên máy

    Khi trang mở, máy cùng loại có thể tải model này trực tiếp từ đây (P2P).

    Phát hiện vật thể

    Máy chưa có model

    Sang tab Model và bấm Xin model trước.

    Tới tab Model

    Bật camera hoặc chụp ảnh để bắt đầu phát hiện vật thể.

      Đánh giá kết quả

      Đánh giá khung hình đã chụp; server dùng để chọn model tốt hơn cho các máy cùng loại.

      Chưa có khung hình nào

      Ở tab Camera, bấm "Đánh giá khung này" hoặc chụp một ảnh.

      Điểm (1 kém – 5 tốt)
      Model nhận đúng vật thể không?
